🧩 OpenHands 核心架構解析

1. Event Stream（事件流驅動）

核心採用 Action 與 Observation 的事件循環。Agent 輸出 Action，環境執行後返回 Observation 給 LLM 解析處理。

2. Runtime & Sandbox（安全沙盒）

所有程式碼執行與 Bash 指令均在隔離的 Docker 沙盒環境中完成，保障宿主機安全。
